# Компьютерная графика

Лабораторные расположены в отдельных каталогах.

- [ЛБ6 — Геометрические преобразования](lb6/README.md): **готовый полный комплект**, индивидуальный номер 28, вариант `28 % 20 = 8`. Исходники Go, настольное приложение Linux, результаты и отчёт.

## ЛБ6

Запуск:

```bash
cd lb6
./bin/lab6-linux-amd64
```

Go устанавливать не нужно. Для настольного окна требуется Linux с X11/XWayland.
