Реальные снимки окна и увеличенных фрагментов сохранены в report/interface.png и report/interface-zoom.png. Сообщения XGB о .Xauthority относятся к изолированному локальному Xvfb; соединение и тест успешны.

Go установлен в среде сборки; доказательство автономного исполнения состоит в запуске статического файла с PATH, в котором Go отсутствует. Для окна необходим X11/XWayland. Пакетный режим работает без графического сервера. Команды воспроизведения приведены в README.
