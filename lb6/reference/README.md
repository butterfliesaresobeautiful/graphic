# Источники

`lab6-manual-pages-115-128.pdf` — страницы 115–128 пользовательского практикума «Компьютерная графика: введение в обработку изображений», ЮЗГУ, 2024. Извлечены без изменения содержимого страниц. Задание ЛБ6, цель, таблица вариантов и требования к отчёту взяты отсюда. В таблице максимальный номер — 20; строка 8: поворот, отражение; i = x′^(5/3), j = y′.

`TSOS_Lab4_Variant7.docx` — пользовательский пример отчёта по другому предмету, использован только как образец стиля. Его задание и вариант не применяются к ЛБ6. `style.json` содержит извлечённые параметры оформления. Приоритет имеет методичка по компьютерной графике.
