# Источник задания

`lab2-manual-pages-23-47.pdf` — неизменённые страницы 23–47 приложенного пользователем сборника `практикум_комп_обраб_изображений_8.pdf`. Лабораторная № 2, цель на с. 23, требования к содержанию отчёта на с. 31, таблица вариантов на с. 32–33. Максимальный номер 20: 28 % 20 = 8. Форма — круг внизу слева, новое положение сверху по центру, функция y=x³.

Пример отчёта `TSOS_Lab4_Variant7.docx` по другому предмету (сохранён ранее в `lb6/reference/`) использован только как ориентир оформления. Задание и содержание отчёта определены методичкой по компьютерной обработке изображений. Личные реквизиты оставлены для заполнения, чужие ФИО не перенесены.
