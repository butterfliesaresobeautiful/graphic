# ЛБ10 — Алгоритмы построения кривых и поверхностей

[Готовый ZIP](dist/lab10-variant12.zip)

Индивидуальный номер 28. Вариант **`28 % 16 = 12`**. Выполнены задания **1, 2, 4 и 6** из [методички Мельник Е. В.](reference/m2664.pdf).

## Запуск на Linux без Go

Распаковать ZIP и из папки `lb10` выполнить на компьютере с процессором Intel или AMD:

```bash
chmod +x bin/lab10-linux-amd64
./bin/lab10-linux-amd64
```

Оба файла статические. Шрифт встроен. Для запуска окна нужен графический сеанс **X11 или XWayland**. Устанавливать Go, Python или дополнительные библиотеки не требуется. AMD64 проверен запуском в X11. ARM64 проверен по заголовкам ELF после перекрёстной сборки.

## Работа с приложением

- **Квадратичная и кубическая кривые.** Щелчок на свободном месте добавляет контрольную вершину в конец списка. Щелчок на вершине выбирает её, перетаскивание меняет координаты. Координаты X и Y можно задать числами в правой панели. Кнопки со стрелками выбирают вершину, сегмент или этап де Кастельжо. На каждом этапе панель показывает рассчитанные промежуточные координаты.
- **Поверхность.** В правой панели задаются число столбцов по u, число строк по v и координаты X, Y, Z выбранной вершины. Общая часть сетки сохраняется при изменении размеров. Выбрать вершину можно щелчком или стрелками. Перетаскивание на свободном месте или правой кнопкой вращает поверхность.
- **Параметры разбиения.** t для выбранного сегмента и u, v для поверхности задаются в диапазоне [0, 1]. Число разбиений определяет количество интервалов для отрисовки. Для кривой оно применяется к каждому сегменту. Для поверхности число интервалов задаётся отдельно в двух направлениях. Enter или переход к другому полю применяет введённое число. Допускается дробная точка или запятая. Esc отменяет редактирование поля.
- **Слои.** Кнопки «Исходные вершины» и «Уточнённые вершины» включают соответствующие контрольные ломаные или сетки. Для кривой показаны две ломаные выбранного сегмента после разбиения в t. Для поверхности показаны сетки четырёх участков после разбиения в u и v.
- **Вид и сохранение.** Колесо мыши меняет масштаб. «Вписать» помещает контрольные вершины в область просмотра. «Демо» возвращает исходный пример текущей вкладки. «Сохранить PNG» записывает текущую область просмотра в каталог `output` рядом с `bin`. Параметр `-out каталог` задаёт другой путь.

Кривая состоит из сегментов степени 2 или 3 с общими конечными точками. Для неполного последнего сегмента степень повышается с сохранением его формы. Пределы ввода составляют 128 контрольных вершин кривой, 16 × 16 контрольных вершин поверхности, 64 интервала на направление и координаты в пределах ±10000.

## Три примера без графического сеанса

```bash
./bin/lab10-linux-amd64 -mode demo -out output
```

Режим сохраняет `quadratic.png`, `cubic.png`, `surface.png` и `metrics.json` с координатами и параметрами примеров. Эти файлы уже есть в `images/`.

## Отчёт и исходники

Для пересборки нужен Go 1.22 или новее. Зависимости и лицензии включены в папки `vendor/` и `third_party/`.

```bash
CGO_ENABLED=0 GOOS=linux GOARCH=amd64 GOAMD64=v1 go build -mod=vendor -trimpath \
  -ldflags='-s -w' -o bin/lab10-linux-amd64 ./cmd/lab10
CGO_ENABLED=0 GOOS=linux GOARCH=arm64 go build -mod=vendor -trimpath \
  -ldflags='-s -w' -o bin/lab10-linux-arm64 ./cmd/lab10
go test -mod=vendor -count=1 ./...
go vet -mod=vendor ./...
```

Оконная проверка с воспроизведением снимков описана в [протоколе](validation/README.md). Для пересборки отчёта используются Python с python-docx, Pillow и PyMuPDF, Inkscape, LibreOffice и Times New Roman.

```bash
./bin/lab10-linux-amd64 -mode demo -out images
python tools/build_diagrams.py
python tools/build_report.py
soffice --headless --convert-to pdf --outdir report report/report.docx
python tools/check_format.py
python tools/check_report.py
python tools/package.py
sha256sum -c SHA256SUMS
```
