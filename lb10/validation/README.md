# Проверки ЛБ10

- `go-test.txt` фиксирует пять успешных тестов. Они проверяют промежуточные вершины, сохранение формы после уточнения и повышения степени, произвольные размеры сетки, ввод параметров и настоящее окно X11.
- `go-vet.txt` содержит вывод проверки Go. Пустой файл означает отсутствие замечаний.
- `elf.txt` содержит архитектуры, параметры сборки и заголовки готовых статических бинарников.
- `report-check.json` фиксирует сверку полного листинга с исходниками, восемь вопросов, иллюстрации и границы содержимого PDF.
- `format-check.json` фиксирует сопоставление титульного листа, стилей, полей и номера страницы с DOCX ЛБ4 и ЛБ6.
- `archive-smoke.json` фиксирует проверку CRC, SHA-256 и повторение трёх примеров из свежей распаковки ZIP с `PATH=/nonexistent` и без `DISPLAY`.

Оконный тест запускает готовый AMD64-бинарник с `PATH=/nonexistent`. После ввода чисел, изменения числа вершин и переключения слоёв он сравнивает сохранённый PNG с отдельно построенной сценой. Четыре иллюстрации в отчёте получены чтением пикселей окна X11. ARM64 прошёл перекрёстную сборку и проверку ELF.

Для повторения оконного теста на отдельном экране:

```bash
Xvfb :103 -screen 0 1440x1050x24 -nolisten tcp &
DISPLAY=:103 LAB10_GUI_BINARY="$PWD/bin/lab10-linux-amd64" \
  LAB10_GUI_CAPTURE_DIR="$PWD/report" go test -mod=vendor -count=1 -v ./...
```
