# Проверки новой реализации ЛБ2 — 30.10.2026

- `go-test.txt`: 10 PASS, включая настоящий оконный тест X11. Xvfb :99, 1440×1080×24; бинарник amd64 запущен тестом с PATH=/nonexistent. Сообщение xgb об отсутствии .Xauthority относится к изолированному локальному Xvfb, после него соединение и тест прошли.
- `go-vet.txt`: успешный go vet; пустой файл означает отсутствие диагностик.
- `elf.txt`, `elf-amd64.txt`, `elf-arm64.txt`: статические ELF без INTERP. Версия ARM64 на ARM не исполнялась.
- `build-amd64.txt`, `build-arm64.txt`: сведения Go о сборке, CGO_ENABLED=0.
- `runtime.txt`, `runtime-trace.txt`: batch с PATH=/nonexistent и без DISPLAY; код завершения 0. Трассировка execve/connect показывает только сам исполняемый файл, без дочерних программ и сетевых соединений. Все пять PNG и metrics.json побайтово совпали с images/.
- `report-check.json`: DOCX и PDF, полный собственный листинг, точные цель/вывод, все 14 вопросов, 9 иллюстраций, A4, Times New Roman 14, межстрочный интервал 1,5, поля 30/15/20/20 мм; выходов за поля нет.
- `archive-smoke.json`: свежая распаковка ZIP, CRC, все контрольные суммы, запуск amd64 без Go в PATH, сравнение пяти PNG и JSON.

Настоящие снимки окна находятся в `../report/interface.png` и `../report/interface-stages.png`. Они сделаны X11 GetImage в тесте, который вводит размер, создаёт холст до открытия источника, выбирает файл, выполняет перенос/оси/график и сохраняет результат. Сохранённые пиксели сравниваются с вычислительным ядром.

Пакетный режим и GUI используют одно ядро. Проверены попиксельное сохранение RGB (15373 точки при R=70), отсутствие изменений вне круга, частичное отсечение, координаты 0, непустое начало прямоугольника, отсутствие результата, порядок операций, сохранение прежнего результата при ошибках, повторные оси/график, отображение аналитических точек x³, альфа-вход и защита исходника через пути и ссылки.

Для воспроизведения команд см. `../README.md`. Наличие Go в среде разработки не мешает проверке автономного бинарника: дочерние запуски имеют PATH, в котором Go отсутствует. Полноценный Linux-десктоп всё равно должен предоставлять X11/XWayland.
