# Проверки ЛБ4

- `go-test.txt` — все 10 тестов PASS: геометрия постоянной ширины, радиальная погрешность и связность, симметрия, перенос и вершины, целочисленный инвариант, отсечение, ввод-вывод и ошибки, X11-примитив, CLI и настоящее окно готового бинарника.
- `go-vet.txt` — пустой вывод успешного go vet, код завершения 0.
- `elf*.txt` — статические Linux ELF для amd64/arm64, отсутствие INTERP.
- `build-*.txt` — версии и флаги фактически собранных бинарников.
- `runtime.txt`, `runtime-trace.txt` — amd64 с env -i PATH=/nonexistent DISPLAY=:99; один execve, соединения с локальным X-сервером, без дочерних команд. Семь PNG побайтово совпали с images.
- `report-check.json` — полный собственный код совпадает с DOCX/PDF (для PDF без учёта пробелов), точные цель и вывод, четыре вопроса, 14 иллюстраций, A4, поля и шрифты. Страницы также просмотрены визуально.
- `archive-smoke.json` — проверка контрольных сумм и запуск из свежей распаковки ZIP с PATH=/nonexistent. После добавления протокола финальный архив повторно распакован и проверен скриптом tools/package.py.

Xvfb используется только для проверки в облачной среде. На компьютере преподавателя приложение обращается к обычному X11/XWayland. Batch тоже требует X-сервер для четвёртого метода. ARM64 не исполнялась; независимость от Go проверена PATH и отсутствием дочерних команд, а не отдельным контейнером.
