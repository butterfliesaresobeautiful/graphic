# Протоколы проверки ЛБ6

- `go-test.txt`: 9 PASS, включая настоящее окно готовой amd64-сборки на Xvfb. Дочерний GUI-процесс запущен с PATH=/nonexistent; проверены выбор файла, выполнение и сохранение всех трёх результатов.
- `go-vet.txt`: пустой вывод успешной команды, код завершения 0.
- `elf*.txt`: обе архитектуры, статическая линковка, отсутствие INTERP.
- `build-*.txt`: версии и параметры фактических бинарников.
- `runtime.txt`, `runtime-trace.txt`: консольный запуск с env -i PATH=/nonexistent; один execve, нет connect. Три PNG совпали с images побайтово.
- `report-check.json`: проверка полного кода и структуры DOCX, вопросов, цели/вывода, размеров и текста PDF, наличия изображений и шрифтов. Визуально также просмотрены все страницы PDF.
- `archive-smoke.json`: запуск из отдельно распакованной копии комплекта, сравнение PNG и проверка контрольных сумм. Итоговый ZIP дополнительно распакован и проверен после добавления этого протокола.
- `container-attempt.txt`: неуспешная дополнительная попытка bwrap; user namespace запрещён средой (`Read-only file system`). Изолированный контейнер без Go не проверен.

ARM64 только кросс-компилирована и исследована, не исполнена. Отсутствие Go в PATH не равнозначно физическому отсутствию Go во всей файловой системе. Проверка независимости основана также на статическом ELF и отсутствии запуска вспомогательных процессов.
