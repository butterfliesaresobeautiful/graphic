# Компьютерная графика

Лабораторные расположены в отдельных каталогах.

Лабораторные находятся в отдельных папках. Для каждой подготовлены исходники Go, готовые десктопные Linux-приложения, результаты, отчёты DOCX/PDF и полный ZIP. Индивидуальный номер 28, вариант каждой работы: `28 % 20 = 8`.

- [ЛБ2 — Программа для формирования изображений](lb2/README.md): переписана заново 30.10.2026. Попиксельный перенос круга, оси, график y=x³.
- [ЛБ4 — Растеризация окружностей](lb4/README.md): треугольник Рёло заданной ширины, четыре метода.
- [ЛБ6 — Геометрические преобразования](lb6/README.md): аффинное и нелинейное преобразования, восстановление.

## ЛБ2

```bash
cd lab2-variant8
chmod +x bin/lab2-linux-amd64
./bin/lab2-linux-amd64
```

## ЛБ4

```bash
cd lb4
./bin/lab4-linux-amd64
```

Go не нужен. Требуется X11/XWayland; четвёртый способ использует настоящий примитив X11 PolyArc.

## ЛБ6

Запуск:

```bash
cd lb6
./bin/lab6-linux-amd64
```

Go устанавливать не нужно. Для настольного окна требуется Linux с X11/XWayland.
